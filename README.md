# ODataSample

This project is a sample implementation of a .NET 8 Web API with OData integration, demonstrating how to query sample data with Entity Framework Core's in-memory database provider.

## Features

- **OData Integration**: Enables querying, filtering, and managing data with OData.
- **Entity Framework Core**: Uses EF Core for data access and management.
- **In-Memory Database**: Seeds sample Companies and Products when the app starts.

## Getting Started

### Prerequisites

- .NET 8 SDK
- Visual Studio or any C# IDE

### Installation

1. Clone the repository:
   ```sh
   git clone https://github.com/sannlynnhtun-coding/ODataSample
   cd ODataSample
   ```

2. Run the application:
   ```sh
   dotnet run
   ```

### Usage

- Access the API at `https://localhost:7007/api/Companies` or `http://localhost:5142/api/Companies`
- Use OData queries to manage and filter data.
